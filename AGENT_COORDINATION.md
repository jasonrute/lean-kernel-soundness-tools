### Agent isolation rules

- **One file per task.** If a task touches multiple files, coordinate which file before starting.
- **No cross-branch dependencies.** Each branch is self-contained.
- **No shared working directories.** Each agent works in their own worktree.
- **Commit frequently.** Small commits = easier conflict resolution if anything goes wrong.
- **Push after each commit.** `git push` so other agents can see progress.
- **Avoid `git pull` on shared branches.** Only pull from `main`.
